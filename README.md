## Selected projects

### [Archon](https://github.com/Vyshnavi-d-p-3/Archon)
An LLM agent framework with a planner, executor, and reflector loop. Typed tool calls, tracing, retry policies, and execution budgets make runs easier to inspect. The evaluation harness includes deterministic test backends, run manifests, and statistical comparisons.

**Python, async orchestration, LLM evaluation**  
[Architecture](https://github.com/Vyshnavi-d-p-3/Archon#architecture) | [Research methodology](https://github.com/Vyshnavi-d-p-3/Archon/blob/main/docs/RESEARCH.md)

### [Sentinel](https://github.com/Vyshnavi-d-p-3/Sentinel)
An AI code review platform combining lexical and vector retrieval with structured LLM reviews and per-PR cost limits. Its evaluation harness uses 98 synthetic fixtures to measure precision, recall, and F1 by issue category.

**Python, FastAPI, PostgreSQL, pgvector, Next.js**  
[Architecture](https://github.com/Vyshnavi-d-p-3/Sentinel#architecture) | [Evaluation methodology](https://github.com/Vyshnavi-d-p-3/Sentinel#evaluation-methodology)

### [Helios](https://github.com/Vyshnavi-d-p-3/Helios)
A time-series database in Go exploring durable ingestion, WAL and LSM storage, Gorilla compression, and indexed queries. Supports a PromQL subset, streaming anomaly detection, and optional three-node Raft replication.

**Go, storage engines, Prometheus APIs, Raft**  
[Architecture](https://github.com/Vyshnavi-d-p-3/Helios#architecture) | [Benchmarks](https://github.com/Vyshnavi-d-p-3/Helios#performance)

### [Kairos](https://github.com/Vyshnavi-d-p-3/Kairos)
A multi-tenant OKR application exploring PostgreSQL Row-Level Security, safe tenant context in pooled connections, idempotent writes, and Redis rate limiting. Documents the isolation model and current limitations.

**Java, Spring Boot, PostgreSQL, Redis, TypeScript**  
[Tenant isolation](https://github.com/Vyshnavi-d-p-3/Kairos#how-tenant-isolation-works) | [Limitations and tradeoffs](https://github.com/Vyshnavi-d-p-3/Kairos#status-and-limitations)

Other work includes [NeuroLens](https://github.com/Vyshnavi-d-p-3/NeuroLens), an adversarial ML toolkit with from-scratch PyTorch models and cross-modal transfer experiments, and [AdaptiveRateGuard](https://github.com/Vyshnavi-d-p-3/AdaptiveRateGuard), a Redis/gRPC rate limiter with a predictive traffic sidecar.
